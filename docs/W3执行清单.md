## 🔴 两个「和教程不一样」的坑（我已核对官方文档）

### 坑 1：`temperature` 和 `top_p` 的作用被 mode 互斥

| 参数 | 非思考模式（`thinking: disabled`）| 思考模式（`thinking: enabled`）|
|---|---|---|
| `temperature` | ✅ **生效**（0–2，默认 1）| ❌ **不生效** |
| `top_p` | ❌ **恒为 1.0，传了也被忽略** | ✅ 生效（0.95–1.0，低于 0.95 按 0.95）|

> **绝大多数教程说"调 temperature 或 top_p 二选一"——在 DeepSeek 上这不是二选一，
> 而是「你开没开思考模式」决定哪一个有效。**
> 你现在用的是 `thinking: disabled` → **只调 `temperature`，`top_p` 白传。**

### 坑 2：`frequency_penalty` / `presence_penalty` 已废弃

官方原文：*"该参数已不再支持。传入该参数将不会产生任何效果。"*
**别抄老教程里的这两个参数，纯噪音。**

## 📡 SSE 格式（本周要能默写）

```
data: {"id":"abc","object":"chat.completion.chunk","choices":[{"index":0,"delta":{"role":"assistant","content":""},"finish_reason":null}]}

data: {"id":"abc","object":"chat.completion.chunk","choices":[{"index":0,"delta":{"content":"你"},"finish_reason":null}]}

data: {"id":"abc","object":"chat.completion.chunk","choices":[{"index":0,"delta":{"content":"好"},"finish_reason":null}]}

data: {"id":"abc","object":"chat.completion.chunk","choices":[{"index":0,"delta":{},"finish_reason":"stop"}],"usage":{"prompt_tokens":17,"completion_tokens":2,"total_tokens":19}}

data: [DONE]
```

**三条铁律**：

1. 每条消息以 **`data: `** 开头，帧之间用 **两个换行 `\n\n`** 分隔。
2. 内容是 **增量**（`delta.content`），不是全量——要自己拼。
3. 以 **`data: [DONE]`** 结尾，**它不是 JSON，别 `JSON.parse`**。

**`usage` 在哪？**（官方说明）

- 不用 `stream_options` 也会有：**`[DONE]` 之前的最后一个块**带 `usage`。
- 那个块的 `choices` 只含一个元素，**不含新增内容**，`finish_reason` 非 null。
- 想每块都带 `usage` 字段（其余为 null）→ 传 `stream_options: { include_usage: true }`，
  且**必须同时 `stream: true`**，否则返回 **400**。

## Day 18（周四 · 1h）· 手写解析，逐字打印

### 目标：**这一周的核心**——把 SSE 拆成文字

### 步骤

**1. 解析骨架（40 min）**

```js
const reader = res.body.getReader();
const decoder = new TextDecoder();
let buffer = '';                                  // ← 关键：累积半包

while (true) {
  const { done, value } = await reader.read();
  if (done) break;

  buffer += decoder.decode(value, { stream: true });   // ← stream:true 防中文截断

  const frames = buffer.split('\n\n');                  // ← 按空行切帧
  buffer = frames.pop();                                // ← 最后一段可能不完整，留到下次

  for (const frame of frames) {
    const line = frame.trim();
    if (!line.startsWith('data: ')) continue;

    const payload = line.slice(6);                      // 去掉 "data: "
    if (payload === '[DONE]') return;                   // ← 结束，别 parse

    const json = JSON.parse(payload);
    const text = json.choices?.[0]?.delta?.content;
    if (text) process.stdout.write(text);               // ← 逐字输出
  }
}
```

**2. 跑通并对比（20 min）**

```
旧版（stream:false）：等 2 秒 → 一次性蹦出全文
新版（stream:true ）：立刻开始，一个字一个字蹦
```

## Day 19（周五 · 1h）· 三个必踩的坑

### 目标：让流式**稳**，不是"能跑"

### 坑 1：`[DONE]` 不是 JSON

```js
JSON.parse('[DONE]')   // ❌ SyntaxError: Unexpected token D
```

✅ 解法：`if (payload === '[DONE]') break;`

### 坑 2：半包（一个 JSON 被切成两段）

```
第一次读到：data: {"choices":[{"delta":{"content":"你
第二次读到：好"}}]}\n\n
```

如果每次都 `JSON.parse(buffer)` → **必然崩**。

✅ 解法：`buffer` 累积 + `split('\n\n')` + `pop()` 留尾巴。

### 坑 3：中文多字节被截断

`"你"` 的 UTF-8 是 3 个字节，可能正好被切在 chunk 边界上。

```js
new TextDecoder().decode(bytes)                  // ❌ 可能出现 �
new TextDecoder().decode(bytes, { stream: true }) // ✅ 保留未完成的字节
```

### 动手验证（40 min）

**故意制造这三个坑**，各贴一段证据：

```bash

# 坑 2：把 buffer 去掉，直接用 split，看崩在哪
# 坑 3：去掉 { stream: true }，用长中文回复，看有没有 �
```

### 目标：从"能用"到"能控"

### 步骤

**1. 加模板（40 min）**

```js
function buildMessages({ system, examples = [], user }) {
  return [
    { role: 'system', content: system },
    ...examples.flatMap(([q, a]) => [
      { role: 'user', content: q },
      { role: 'assistant', content: a },
    ]),
    { role: 'user', content: user },
  ];
}
```

> **few-shot 的位置**：示例放在 system 之后、真正的问题之前，

## 🚨 常见报错速查（W3 专属）

| 报错 | 原因 | 解决 |
|---|---|---|
| `HTTP 400` + `stream_options` | 传了 `stream_options` 但没 `stream: true` | 两个一起传 |
| `SyntaxError: Unexpected token D` | 对 `[DONE]` 做了 `JSON.parse` | 先判断 `payload === '[DONE]'` |
| `SyntaxError: Unexpected end of JSON input` | 半包，JSON 被切断 | `buffer` 累积 + `pop()` 留尾 |
| 输出里出现 `�` | 中文多字节被截断 | `decoder.decode(value, { stream: true })` |
| 一直不输出、最后一次性蹦出 | 忘了 `stream: true` | 检查请求体 |
| `res.body` 是 `null` | 非流式响应 / 请求失败 | 先检查 `res.ok` |
| `temperature` 改了没效果 | 你开着思考模式 | `thinking: { type: 'disabled' }` |
| `top_p` 改了没效果 | 非思考模式下它恒为 1.0 | 用 `temperature` |
